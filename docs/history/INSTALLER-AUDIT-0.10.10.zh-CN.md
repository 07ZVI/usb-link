# 0.10.10 安装链路审查

本轮以受影响 Windows 返回的 0.10.7–0.10.9 报告为依据，检查构建产物、预检、组件准备、旧残留清理、候选文件落盘、发布、服务注册/启动、初始化确认、回退及失败报告。它不是 Windows 实机验收结论，也不承诺排除所有环境问题。

## 已确认的问题与修复

| 问题 | 证据 | 修复 |
| --- | --- | --- |
| 发布包缺少桌面清单 | 0.10.9 返回 `INSTALL_PUBLISHER_DESKTOP_INDEX_REQUIRED`；对旧 `desktop.zip` 运行新增真实产物测试可复现 | 构建时生成完整 `desktop-ownership.json`，由实际安装器消费代码核验每个文件 |
| 真实产物测试被跳过 | 原测试必须设置 archive 环境变量，但构建入口未设置 | 构建必跑实际归档测试；最终 EXE 再核对嵌入归档并执行生产文件操作 |
| 有缺陷的包能先清理旧记录 | 原完整清单检查在 `InstallRelease` 内、向导清理之后；报告中旧服务和登记已不存在 | 包的格式、清单、所有文件 SHA256、必需桌面文件、事务大小检查提前到组件准备和旧残留删除之前；安装入口重复检查 |
| 增量发布目录可能带入旧文件 | 原构建复用 `out/desktop`，重新收集整个目录 | 每次使用独立临时发布目录，发布完成后对实际输出生成清单 |
| 独立检查只返回第一个错误 | 旧残留预检先后返回注册表和服务错误 | 独立的目录、进程、登记、服务检查汇总错误；服务命令、元数据、执行/恢复策略、运行状态汇总；所有检查仍须通过才允许清理 |
| 安装报告不完整、字段容易误读 | 旧报告缺少服务显示名等字段；`changesMade:false` 实际只描述只读检查 | 使用 `inspectionReadOnly`；记录安装前状态、阶段事件、组件状态、清理备份路径、事务摘要、服务配置/恢复配置/退出码、目录保护和待重启删除检查 |

0.10.8 对已报告的继承注册表权限、0.10.9 对旧服务显示名称的兼容修复保留。它们仅用于已删除旧安装的严格清理，不授权执行卸载字符串或接管不明服务。新版也不要求用户删除 ProgramData 或恢复日志。

## 验证范围

- 真实桌面归档：32 个条目，全部内容与清单逐项匹配。
- 实际发布清单：34 个文件（桌面条目加核心程序及发布凭据）。运行生产暂存、重复执行、复制发布、磁盘校验、清理算法；验证首次安装及升级事务能序列化并符合限制。
- 最终 Windows EXE：包含本轮核验过的归档，并作为真实核心源文件再次运行上述文件契约测试。外部安装包的权限与安装目标权限分开检查，支持从下载目录或 USB 盘运行。
- 故障测试：缺清单、多个文件内容错误、危险路径、7 个逐文件发布中断点及恢复；保留既有文件占用、外来内容保护、身份变化、取消、服务启动/初始化失败回退、已接受后清理重试、注册表写入/读回/刷新失败测试。
- 全项目 `go test -race ./...`、Windows 交叉构建及静态检查、架构边界和差异格式检查。
- 增加独立 Windows 原生存储测试：在临时目录验证真实 ACL 继承、事务写入读回、暂存/发布/清理，不操作产品服务或安装位置。本机只能编译该测试，尚未在 Windows 执行。

## 必须保留的实机边界

Mac 上的上述验证不能证明目标 Windows 的 UAC、SCM 服务创建/启动、系统安全策略、杀毒软件占用、任务计划程序、现存 USB/网络恢复日志、驱动及设备状态都能通过。启动成功仍要求原有的来源验证和初始化确认；没有因为本轮诊断而跳过这些条件。

0.10.9 在发现缺清单之前已经建立了受保护目录，但尚未走到新安装事务保存。新版本按正常预检处理这些目录，不需再次手动删除。最终以新报告中的事务、安装前后状态和初始化结果为准。
