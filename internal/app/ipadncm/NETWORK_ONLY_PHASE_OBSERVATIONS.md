# Once-only I7 phase observations

The fixed authenticated USB diagnostics `IPADNETWORKONLYPHASEON` and `IPADNETWORKONLYPHASEOFF` arm or stop process-memory capture. Capture defaults OFF after every process start, expires after 120 seconds, selects only the first nonzero connection attempt, and deducts cumulative observation time from a two-second budget. No timer, idle polling, device/service mutation, pairing action, authorization import or free-form command is introduced. `IPADNETWORKONLYSTATE` reads capture status and the latest 32 records.

Ensure records entry, its actual PRESENT portable enumeration (including its error), and exit for before_driver, after_driver and after_mode. Exit success describes only the Ensure result. It is not continuous isolation, prompt attribution, or proof that no later instance appeared. Selected-attempt phase completeness must be checked: budget, cancellation, feature disable, TTL or the history cap can omit records. Unknown count is null, complete empty count is zero. Fresh all-enumerator PRESENT WPD/Image rows and receipt-owned ALL-instance rows remain separate. Full native IDs are matched locally and exported only as domain-separated digests; class metadata never grants software reconnect admission.

The budget is checked between collector operations, including after descriptor enumeration, service queries, PRESENT enumeration, receipt reads, and ALL-instance reads. A synchronous native call/helper cannot be preempted; its duration can exceed the remaining budget, after which later reads stop. Observations are sequential rather than atomic, and may change startup timing. Each record exports observation duration. Diagnostic-enabled samples must not be reported as unobserved U1 latency comparisons. Native Windows behavior is not proven by cross-compilation or portable tests.
